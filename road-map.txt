🧠 3️⃣ LES MATHS (SANS SE FAIRE MAL)


🔢 C’est quoi un nombre complexe ?


Un nombre complexe = un point.

z = a + bi

    a → axe horizontal (x)

    b → axe vertical (y)


👉 Rien de magique.

🔁 La formule magique (Mandelbrot)

z₀ = 0
zₙ₊₁ = zₙ² + c

👉 Traduction humaine :

    Tu pars de 0

    Tu fais une opération

    Tu recommences

    Tu regardes si ça explose 💥

🧪 C’est quoi “ça explose” ?


Si :

|z| > 2

Alors → ça diverge

👉 On arrête la boucle.

🧮 Calcul de z² (sans magie)


Si :

z = x + yi

Alors :

z² = (x² - y²) + 2xyi

💡 Pas besoin de maths avancées.

🖼️ Pixel → monde fractal

c.re = min_x + (x / width) * (max_x - min_x);
c.im = max_y - (y / height) * (max_y - min_y);

👉 C’est juste une règle de trois.

🎨 Couleurs (simple mais beau)

color = iteration * 0x0000FF;
